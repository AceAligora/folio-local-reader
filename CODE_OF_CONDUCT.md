# Community guidelines

Contributors and users should communicate respectfully, welcome different levels of experience, and give specific, constructive feedback. Harassment, threats, discrimination, unwanted sexual attention, and publication of another person's private information are unacceptable.

Keep issue reports focused on reproducible software behavior. Do not post copyrighted ebook files without permission, private library exports, credentials, or personal paths.

Maintainers may remove harmful content and restrict participation when necessary. Report security vulnerabilities using SECURITY.md. Non-sensitive moderation concerns can be raised in an issue addressed to the maintainers; never include personal information, private messages or exploit details in a public issue.
